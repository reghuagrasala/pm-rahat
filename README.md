# 🚑 PM-RAHAT Emergency Assistant (PWA)

A lightweight, single-page Progressive Web App (PWA) built for instant road accident emergency response under the **PM-RAHAT** (*Prime Minister – Road Accident Victims' Hospitalisation & Assured Treatment*) scheme.

## ⚡ Key Features
- **One-Tap 112 Dispatch + GPS Copy:** Fetches high-accuracy GPS coordinates, formats a Google Maps link, copies the location to the clipboard for the 112 operator / e-DAR log, and initiates the emergency call.
- **Golden Hour Hospital Locator:** Opens nearby emergency hospitals and trauma centers directly in Google Maps.
- **Designated Hospital Verification:** Direct link to the official AB PM-JAY / NHA Empanelled Hospital directory (`hospitals.pmjay.gov.in`).
- **24x7 NHA Helpline:** One-tap dialing to `14555` for hospital desk verification or grievance support.

## 📋 PM-RAHAT Scheme Quick Reference
- **Coverage:** Up to **₹1.5 Lakh** cashless treatment per road accident victim.
- **Validity:** Up to **7 days** from the date of hospitalization.
- **Eligibility Window:** Hospitalization must occur within **24 hours** of the road accident.
- **Hospitals Covered:** All AB PM-JAY empanelled hospitals (plus 24–48 hour emergency stabilization at non-designated hospitals).

## 📱 How to Install on iPhone (Home Screen or Shortcut)
1. **As a Web App:** Open the hosted GitHub Pages / Cloudflare Pages URL in **Safari**, tap the **Share** button, and select **Add to Home Screen**.
2. **As an Apple Shortcut:** Open the **Shortcuts** app → Tap **`+`** → Add the **Open URLs** action → Paste your hosted URL → Pin to Control Center or Lock Screen.

## 🔒 Privacy
Zero analytics, zero external tracking scripts. Location data is processed strictly on-device via the browser's native Geolocation API only when triggered by the user.
